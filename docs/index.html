RECURSIVE SELF-IMPROVEMENT · 试点：指令微调

基于大模型后训练的
指令微调自进化系统 RSI

冠军模型自己出题、自己作答，由程序验证筛出合格样本作为训练数据；元优化器自动提出训练配方，训练、评测后经统计门控决定是否晋升，再反思调整下一代策略——全程无人工标注。

核心结果

项目内测试集（200 道带可验证约束的指令 + 150 道 GSM8K），从不参与任何选择或晋升决策。对比原始基座与系统自主选出的当前冠军。

一代 = 一次完整的自我改进闭环

深色三步是“自”的部分：数据由模型自己产生、由程序自己验证、晋升由统计自己决定。

① 诊断

读取冠军在各约束类型上的通过率，找出弱项。

② 自生成

冠军按弱项加权出题，每题采样 k 次作答；数学题自举推理链（STaR）。

③ 验证筛选

18 类约束程序化校验、数学答案与推理链校验、实质内容过滤，只留合格样本。

④ 配方提议

元优化器对冠军配方施加改动算子（Thompson 采样学习哪类改动有效；失败定向修复）。

⑤ 训练评测

LoRA SFT 训练多个候选，在每代新抽的门控集上与冠军同场评测。

⑥ 门控反思

综合分更优、配对 bootstrap P(更优) ≥ 0.8、数学与退化守护指标不回退才晋升；否则回滚并记录经验。

进化过程

折线为每代结束时“冠军”在测试集上的表现（未晋升的代沿用上一冠军）。悬停查看数值；展开下方每一代查看候选、门控结论与系统的反思日志。

第三方验证：官方 IFEval

项目内测试集的约束模板与训练同源，可能高估泛化，因此在 google/IFEval 全部 541 题 上用官方判分代码（lm-eval 实现）复核。生成设置与项目内评测一致（ChatML、贪心、最长 1280 token），与公开榜单的提示格式不同，绝对值不宜直接横比。

能力诊断

各约束类型的通过率（测试集），按提升幅度排序；以及元优化器学到的“哪类改动更可能有效”。

改动算子成功率（Beta 后验均值，已尝试）

每个版本都由上一轮运行暴露的证据驱动。门控标准全程未放宽——先看到结果再改晋升条件，等于移动球门。

复现与局限

单张 RTX 4090（24GB），Windows，Python 3.11：

python -m venv .venv && .venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cu128
pip install transformers peft datasets accelerate gradio python-pptx matplotlib pandas pyyaml "lm-eval[ifeval]"
python -m rsi.prepare                                   # 下载 Qwen3-1.7B-Base 与数据
python -m rsi.loop --config configs/pilot.yaml          # 自进化（可断点续跑）
python -m rsi.ifeval_official                           # 官方 IFEval 复核
python app/demo.py --run pilot                          # 完整交互 demo（含实时对话）
局限
  • 验证器只查格式不查内容质量，会被钻空子；已加实质性过滤与稳健口径，但仍需内容评审。
  • 1.7B 模型、单卡、每代 3 个候选，搜索空间受算力限制；部分代之间差异在统计噪声内。
  • 本页是静态演示；实时对话与“继续进化”需在本地运行 app/demo.py。
